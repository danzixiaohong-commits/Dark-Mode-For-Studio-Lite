# Studio Lite DarkMode

A dark mode plugin for **Studio Lite**.

## Usage

1. Copy the script from this repository into a script inside your Studio Lite project.
2. You can customize the colors in the **Settings** section located at the very top of the script.
3. Click **"Play"** to enable DarkMode (works just like any other Studio Lite plugin).
